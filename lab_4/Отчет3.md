## 1. Цель работы

## 2. Теоретические сведения

Динамический массив создаётся во время выполнения программы с помощью `new[]`. Для освобождения памяти используется `delete[]`.

Правило трёх включает три специальных метода:
- конструктор копирования;
- оператор присваивания;
- деструктор.

Они необходимы для правильного управления памятью при копировании объектов, содержащих указатели.

## 4. Контрольные вопросы

**1. Чем динамическая память отличается от статической?**  
Динамическая выделяется во время выполнения программы, статическая — заранее.

**2. Для чего нужны `new[]` и `delete[]`?**  
Для выделения и освобождения памяти массива.

**3. Что такое правило трёх?**  
Это правило, согласно которому при необходимости определяют конструктор копирования, оператор присваивания и деструктор.

**4. Чем конструктор копирования отличается от оператора присваивания?**  
Конструктор создаёт новый объект, оператор присваивает данные уже существующему.

**5. Что произойдёт без конструктора копирования у класса с указателем?**  
Может возникнуть поверхностное копирование и двойное освобождение памяти.

**6. Для чего нужен список инициализации?**  
Для инициализации полей класса при создании объекта.

**7. Что такое `this`?**  
Указатель на текущий объект.

**8. Зачем проверять `this != &other`?**  
Чтобы избежать ошибок при присваивании объекта самому себе.

**9. В каком порядке уничтожаются локальные объекты?**  
В обратном порядке их создания.

**10. Чем глубокое копирование отличается от поверхностного?**  
Глубокое копирует данные, поверхностное — только указатель.

**11. Чем отличаются `reserve` и `resize`?**  
`reserve` меняет вместимость, `resize` — размер массива.

**12. Как увеличивается динамический массив?**  
Выделяется больший блок памяти, элементы копируются, старая память освобождается.

**13. Что такое RAII?**  
Принцип управления ресурсами через время жизни объектов.

**14. Когда в `IntVector` может возникнуть утечка памяти?**  
Если не освободить выделенную память или потерять указатель на неё.

**15. Для чего нужны константные методы?**  
Они позволяют вызывать методы у константных объектов, не изменяя их состояние.
